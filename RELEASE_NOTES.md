Download the file for your operating system below, then open http://localhost:3000.

- Windows: TeluguFeeAgent-win-x64.exe  (SmartScreen: More info -> Run anyway)
- macOS (Apple Silicon): TeluguFeeAgent-macos-arm64  (right-click -> Open the first time)
- Linux: TeluguFeeAgent-linux-x64  (chmod +x, then ./TeluguFeeAgent-linux-x64)

Data is saved in a 'data' folder next to the program. For real calling, set Twilio
and Sarvam keys in the dashboard Settings (or a .env file). See README.
